# dotbar

A tiny macOS menu-bar hider. Click the dot: icons to the left of the `|` separator collapse off-screen (and auto-collapse again after 10 s). No permissions, no polling.

- **Setup:** Cmd+drag the `┃` to sit right next to the dot (just left of it); icons left of the `┃` are the ones that hide to make them hideable.
- **Right-click** (or Option-click) the dot for Quit.
- **Build:** `scripts/build-app.sh --install`

Roadmap: bar below the menu bar, icon limit, profiles.
